## Основные понятия

**Токен.** Единица текста, с которой работает модель: слово, знак препинания или часть слова.

**Корпус.** Собрание текстов, по которому оцениваются параметры модели.

**Языковая модель.** Распределение вероятностей $P(w_1,\dots,w_T)$ на последовательностях токенов.

**Цепное правило.** Вероятность последовательности равна произведению вероятностей каждого токена при условии предыдущих: $P(w_1,\dots,w_T)=\prod_{t}P(w_t\mid w_1,\dots,w_{t-1})$.

**N-граммная модель.** Языковая модель, в которой следующий токен зависит только от $n-1$ предыдущих (марковское приближение). При $n=1$ модель называется униграммной, при $n=2$ биграммной, при $n=3$ триграммной.

**Оценка максимального правдоподобия.** Вероятность токена после контекста равна доле случаев, когда этот токен шёл за этим контекстом: $\hat P(w\mid h)=C(h,w)/C(h)$, где $C(\cdot)$ обозначает число вхождений в корпус.

**Разреженность данных.** Большинство возможных n-грамм в корпусе не встречается, и оценка по частотам назначает им нулевую вероятность.

**Закон Ципфа.** Частота слова обратно пропорциональна его рангу в списке слов, упорядоченном по убыванию частоты.

**Закон Хипса.** Размер словаря растёт с длиной текста по степенному закону $V\approx K N^{b}$ при $0<b<1$.

**Сглаживание.** Перераспределение вероятности от встреченных n-грамм к невстреченным, чтобы ни одна n-грамма не имела нулевой вероятности.

**Сглаживание Лапласа (аддитивное).** К каждому счётчику прибавляется число $\delta$: $\hat P(w\mid h)=\dfrac{C(h,w)+\delta}{C(h)+\delta|V|}$, где $|V|$ обозначает размер словаря.

**Откат (backoff).** Переход к модели меньшего порядка, когда нужная n-грамма в корпусе не встречалась.

**Интерполяция.** Смешивание моделей разных порядков с весами, которые в сумме дают единицу.

**Сглаживание Кнесера–Нея.** Метод, который вычитает из счётчиков постоянную величину и оценивает вероятность слова в новом контексте по числу разных контекстов, где оно встречалось.

**Перплексия.** Мера качества языковой модели на отложенном тексте: $\mathrm{PPL}=\exp\big(-\frac1T\sum_t\ln P(w_t\mid\text{контекст})\big)$. Она равна числу равновероятных вариантов, между которыми модель выбирает на каждом шаге. Чем меньше, тем лучше.

**Отложенная выборка.** Часть данных, которая не участвует в обучении и используется для оценки качества.

**Порождение текста.** Последовательный случайный выбор следующего токена из распределения модели. **Температура** делает распределение более острым (меньше единицы) или более ровным (больше единицы).
