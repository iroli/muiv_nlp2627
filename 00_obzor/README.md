# Обзор лекций 1, 2 и 4

`obzor_lekcii_1_2_4.pdf` содержит обзорную презентацию: по десять слайдов на каждую из трёх лекций с основными понятиями и примерами. Она читалась перед лекцией о тематическом моделировании и подходит для повторения перед зачётом.

Последний слайд показывает, какие понятия трёх лекций используются в тематическом моделировании: мешок слов, TF-IDF, перплексия, сглаживание, SVD, PMI, эмбеддинги.
