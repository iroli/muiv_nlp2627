## Основные понятия

**Тематическая модель.** Модель, которая без разметки находит темы коллекции и долю каждой темы в каждом документе.

**Тема.** Распределение вероятностей на словаре: $\phi_{wk}=p(w\mid k)$ обозначает вероятность слова $w$ в теме $k$.

**Профиль документа.** Распределение на темах: $\theta_{kd}=p(k\mid d)$ обозначает долю темы $k$ в документе $d$.

**Основное уравнение.** Вероятность слова в документе равна смеси тем: $p(w\mid d)=\sum_{k}\phi_{wk}\theta_{kd}$. Матрица $\Phi$ хранит темы, матрица $\Theta$ хранит профили документов.

**Документ и слово в общем смысле.** Документом может быть любой объект, описанный набором дискретных событий: клиент банка и категории его покупок, особь и варианты генов, изображение и его фрагменты.

**LSA (латентно-семантический анализ).** Усечённое сингулярное разложение матрицы «слова–документы». Компоненты содержат отрицательные веса и не читаются как вероятности.

**PLSA.** Вероятностная модель, в которой каждое слово документа порождается в два шага: по долям $\theta_d$ выбирается тема, по распределению $\phi_k$ выбирается слово.

**Правдоподобие.** Вероятность наблюдаемой коллекции при данных параметрах. Обучение ищет параметры с наибольшим правдоподобием.

**EM-алгоритм.** Итерационный метод обучения PLSA. На E-шаге для каждого слова оценивается вероятность каждой темы, на M-шаге параметры пересчитываются как частоты.

**LDA (латентное размещение Дирихле).** Модель, в которой векторы $\theta_d$ и $\phi_k$ считаются случайными и подчиняются распределению Дирихле с параметрами $\alpha$ и $\beta$.

**Распределение Дирихле.** Распределение на векторах долей. При параметре меньше единицы случайный вектор сосредоточен на немногих компонентах, при параметре больше единицы компоненты примерно равны.

**Сэмплирование Гиббса.** Метод обучения LDA: тема каждого слова по очереди выбирается заново с вероятностью, пропорциональной $(n_{dk}+\alpha)\cdot\dfrac{n_{kw}+\beta}{n_k+|W|\beta}$, где $n_{dk}$, $n_{kw}$, $n_k$ обозначают счётчики назначений.

**Вариационный вывод.** Метод обучения LDA, который приближает распределение скрытых переменных более простым и подбирает его оптимизацией.

**ARTM (аддитивная регуляризация).** Подход, в котором к логарифму правдоподобия PLSA добавляется взвешенная сумма регуляризаторов: сглаживание, разреживание, декоррелирование тем.

**Модальность.** Отдельный вид «слов» в описании документа со своим словарём: авторы, даты, категории покупок.

**Перплексия тематической модели.** Мера того, насколько хорошо модель предсказывает слова отложенных документов. Чем меньше, тем лучше.

**Когерентность.** Мера смысловой связности главных слов темы. Основана на нормированной поточечной взаимной информации (NPMI) пар слов.

**Число тем $K$.** Гиперпараметр модели. Выбирается по перплексии на отложенных документах, когерентности и читаемости тем.

**BERTopic.** Метод, который находит темы кластеризацией эмбеддингов документов: эмбеддинги, понижение размерности, кластеризация, описание кластера словами по c-TF-IDF.
