## Основные понятия

Ниже приведён краткий список. Полный перечень из 52 определений находится в файле `opredeleniya_i_voprosy.pdf`.

**Нейрон.** Вычисляет взвешенную сумму входов $z=\mathbf w\cdot\mathbf x+b$ и применяет к ней функцию активации: $a=g(z)$.

**Функция активации.** Нелинейная функция между слоями: сигмоида, гиперболический тангенс, ReLU. Без неё несколько слоёв эквивалентны одному.

**Сеть прямого распространения.** Сеть из слоёв, в которой сигнал идёт от входа к выходу. Скрытый слой строит новое представление входа: $\mathbf h=g(\mathbf W\mathbf x+\mathbf b)$.

**Softmax.** Превращает оценки классов в вероятности: $\mathrm{softmax}(\mathbf z)_i=e^{z_i}/\sum_j e^{z_j}$.

**Кросс-энтропия.** Функция потерь для классификации: минус логарифм вероятности, назначенной правильному классу.

**Градиентный спуск.** Обучение малыми шагами против градиента функции потерь: $\mathbf w\leftarrow\mathbf w-\eta\nabla L$, где $\eta$ обозначает скорость обучения.

**Обратное распространение ошибки.** Алгоритм, который вычисляет производные потерь по всем весам за один проход по графу вычислений от выхода к входу.

**Переобучение.** Потери на обучающих данных падают, на проверочных растут. Приёмы против него: ранняя остановка, регуляризация, dropout.

**Эмбеддинги на входе.** Слова заменяются плотными векторами из матрицы эмбеддингов, которая обучается вместе с сетью.

**Рекуррентная сеть (RNN).** Обрабатывает последовательность по одному элементу и передаёт скрытое состояние с шага на шаг: $\mathbf h_t=g(\mathbf U\mathbf h_{t-1}+\mathbf W\mathbf x_t)$.

**Принудительное обучение с учителем (teacher forcing).** При обучении на вход шага подаётся верный предыдущий элемент из данных.

**Затухание градиента.** Градиент уменьшается почти до нуля при обратном распространении через много шагов, и простая RNN не выучивает дальние зависимости.

**LSTM.** Рекуррентная ячейка с отдельной ячейкой памяти и тремя вентилями: забывания, входным и выходным. **GRU** является её упрощённым вариантом.

**Задача seq2seq.** Вход и выход являются последовательностями разной длины: перевод, реферирование.

**Кодировщик и декодировщик.** Кодировщик читает вход и строит его представление, декодировщик порождает выход слово за словом.

**Узкое место.** В модели без внимания весь вход сжимается в один вектор фиксированной длины.

**Внимание.** На каждом шаге декодировщик строит контекст как взвешенную сумму всех состояний кодировщика: $\mathbf c_i=\sum_j\alpha_{ij}\mathbf h^e_j$. Веса $\alpha_{ij}$ получаются функцией softmax от оценок сходства.

**Карта внимания.** Таблица весов внимания: строка соответствует элементу выхода, столбец элементу входа.

**Жадный вывод и лучевой поиск.** Жадный вывод берёт на каждом шаге самое вероятное слово. Лучевой поиск хранит $k$ лучших начал выходной последовательности.
