# Интеллектуальный анализ текстов: материалы пройденных лекций

Курс «Интеллектуальный анализ текстов: от статистических моделей языка до языковых агентов», осенний семестр 2026 года. В репозитории собраны слайды лекций, блокноты семинаров и задания по темам, которые уже прочитаны. К каждой теме приложен краткий список основных понятий и определений.

## Темы

| Папка | Тема | Слайды | Семинары | Самостоятельная работа |
|---|---|---|---|---|
| [`01_statisticheskie_modeli_yazyka`](01_statisticheskie_modeli_yazyka) | Статистические модели языка: n-граммы, сглаживание, перплексия | лекция 1 | корпус и предобработка, n-граммная модель | стихи в стиле Пушкина |
| [`02_klassifikaciya_tekstov`](02_klassifikaciya_tekstov) | Классификация текстов: мешок слов, TF-IDF, наивный Байес, логистическая регрессия, SVM | лекция 2 | три классификатора на одних данных | автор твита: Трамп или Трюдо |
| [`03_tematicheskoe_modelirovanie`](03_tematicheskoe_modelirovanie) | Тематическое моделирование: LSA, PLSA, LDA, ARTM, BERTopic | лекция 3 | тематические модели на практике | темы коротких новостей |
| [`04_vektornye_predstavleniya_slov`](04_vektornye_predstavleniya_slov) | Векторные представления слов: PMI, SVD, word2vec, GloVe, fastText | лекция 4 | обучение word2vec, оценка эмбеддингов | слова и их соседи: новости и Пушкин |
| [`05_nejronnye_seti_seq2seq`](05_nejronnye_seti_seq2seq) | Нейронные сети: нейрон, обучение, RNN, LSTM, seq2seq, внимание | лекция по темам 5 и 6 | нейрон и сеть, RNN и LSTM, seq2seq и внимание | десять задач |
| [`00_obzor`](00_obzor) | Обзор лекций 1, 2 и 4 | обзорная презентация | | |

Внутри папки темы блокноты пронумерованы в порядке прохождения: сначала семинары, последним номером самостоятельная работа. Каждая самостоятельная работа состоит из разобранной части и заданий с самопроверкой.

В каждой папке темы лежит файл `README.md` со списком материалов и основными понятиями темы.

## Как работать с блокнотами

**На своём компьютере.** Нужен Python 3.10 или новее.

```bash
git clone <адрес репозитория>
cd <папка репозитория>
python -m venv .venv
source .venv/bin/activate          # в Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter lab
```

**В Google Colab.** Откройте блокнот из репозитория и выполните в первой ячейке:

```python
!git clone <адрес репозитория> course
%cd course
!pip install -q -r requirements.txt
```

Затем перейдите в папку нужной темы командой `%cd`.

## Данные

Блокноты ищут данные в папке `data` в корне репозитория, поэтому запускать их нужно из папки репозитория или из папки темы.

| Файл | Содержание | Где используется |
|---|---|---|
| `data/pushkin.txt` | стихотворные тексты А. С. Пушкина, 23 тысячи строк | самостоятельные работы тем 1 и 4 |
| `data/lenta_ru_2000.jsonl` | 2000 новостей Lenta.ru с рубриками | семинар темы 3, самостоятельная работа темы 4 |
| `data/lenta_ru_short.jsonl` | 4488 коротких новостей Lenta.ru с рубриками | семинары тем 2 и 5, самостоятельные работы тем 3 и 4 |
| `02_klassifikaciya_tekstov/tweets.csv` | 400 твитов двух политиков | самостоятельная работа темы 2 |

Два семинара темы 1 загружают корпус новостей с HuggingFace Hub, для них нужен доступ в интернет.

## Порядок изучения

Темы идут в порядке программы курса. Лекции читались в порядке 1, 2, 4, 3, затем лекция о нейронных сетях. Перед лекцией 3 был обзор пройденного, он лежит в папке `00_obzor`.

Семинары тем 2, 3 и 5 и разобранные части самостоятельных работ сохранены с результатами выполнения: рисунки и числа видны без запуска. Семинары тем 1 и 4 сохранены без результатов, их нужно выполнить. В заданиях на месте решений стоят многоточия или строка `pass` с пометкой задачи.
