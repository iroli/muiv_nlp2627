## Основные понятия

**Классификация текста.** Задача приписать тексту метку из заданного списка: спам или не спам, тональность, рубрика.

**Мешок слов (BoW).** Представление документа вектором длины $|V|$, где в позиции слова стоит число его вхождений. Порядок слов не учитывается.

**TF-IDF.** Вес слова в документе: частота слова в документе, умноженная на логарифм обратной доли документов с этим словом, $\mathrm{tfidf}(t,d)=\mathrm{tf}(t,d)\cdot\ln\frac{N}{\mathrm{df}(t)}$. Слово, частое в документе и редкое в коллекции, получает большой вес.

**Косинусная близость.** Мера сходства двух векторов, равная косинусу угла между ними.

**Наивный байесовский классификатор.** Выбирает класс с наибольшим значением $P(c)\prod_i P(w_i\mid c)$. Слова считаются независимыми при известном классе.

**Логистическая регрессия.** Вычисляет взвешенную сумму признаков $z=\mathbf w\cdot\mathbf x+b$ и превращает её в вероятность класса сигмоидой $\sigma(z)=1/(1+e^{-z})$. Веса показывают вклад каждого слова.

**Регуляризация.** Штраф за большие веса, который защищает модель от переобучения. В scikit-learn его силу задаёт параметр `C`: чем меньше `C`, тем сильнее штраф.

**Метод опорных векторов (SVM).** Проводит границу между классами на наибольшем расстоянии от ближайших точек обоих классов. Это расстояние называется зазором, ближайшие точки называются опорными векторами.

**Отступ.** Величина $M=y\,(\mathbf w\cdot\mathbf x+b)$ для объекта с меткой $y\in\{-1,+1\}$. Положительный отступ означает верный ответ.

**Функция потерь.** Мера ошибки модели на объекте. У логистической регрессии логарифмическая, $\ln(1+e^{-M})$, у SVM шарнирная, $\max(0,1-M)$.

**Матрица ошибок.** Таблица четырёх исходов двухклассовой задачи: верно найденные (TP), пропущенные (FN), ложно найденные (FP), верно отклонённые (TN).

**Точность (precision).** Доля верных среди объектов, отнесённых к классу: $TP/(TP+FP)$.

**Полнота (recall).** Доля найденных среди объектов класса: $TP/(TP+FN)$.

**F1-мера.** Среднее гармоническое точности и полноты. **Macro-F1** усредняет F1 по классам.

**Доля верных ответов (accuracy).** Доля объектов с верным ответом. При неравных классах эта мера обманчива.

**Точка отсчёта (baseline).** Простейшее решение, с которым сравнивают модель, например постоянный ответ самым частым классом.

**Кросс-валидация.** Оценка качества, при которой данные делятся на $K$ частей и каждая по очереди служит тестом. **Стратификация** сохраняет доли классов в каждой части.

**Утечка данных.** Попадание сведений о тестовых объектах в обучение, например построение словаря по всем данным. Она завышает оценку качества.

**Подсловная токенизация (BPE).** Разбиение слов на части: алгоритм на каждом шаге объединяет самую частую пару соседних символов. Редкое слово собирается из известных частей.
